# PROJECT BOARD — Mehr Panel

این بورد منبع مرکزی مدیریت، اولویت‌بندی و پیگیری چرخه حیات باگ‌ها، ایده‌ها و تسک‌های پروژه «مِهر» است.
اصل کلیدی: هیچ کدی بدون مستندسازی قبلی در این بورد و بدون تست عملیاتی تغییر نمی‌کند.
اصل بازاستفاده: هر قابلیتی که در سیستم موجود است (مانند Proxy IP) باید در سایر بخش‌ها بازاستفاده شود و بازنویسی نشود.

## ۷. راهنمای کدهای فوق‌ساده و سریع پنل (Quick Simple Codes)

- کلیدهای اصلی: `TOP-1` (تم)، `TOP-2` (زبان)، `BOT-1` (ذخیره تنظیمات)، `BOT-2` (خروج)
- تب‌ها:
  - `T1`: نمای کلی (`T1-1` آمار، `T1-2` ترافیک، `T1-3` عملیات سریع)
  - `T2`: نودها (`T2-1` کارت‌ها، `T2-2` کیوآرکد، `T2-3` کلاینت‌ها)
  - `T3`: شبکه (`T3-1` آی‌پی سرور، `T3-2` لوکیشن لبه)
  - `T4`: سرورها (`T4-1` سلامت نودها، `T4-2` مصرف نودها)
  - `T5`: تنظیمات (`T5-1` پورت/پروتکل، `T5-2` رمز/شناسه، `T5-3` بکاپ)
  - `T6`: پیشرفته (`T6-1` آی‌پی تمیز، `T6-2` پروکسی‌آی‌پی، `T6-3` روتینگ، `T6-4` آپ‌استریم، `T6-5` اشتراک، `T6-6` پروتکل، `T6-7` سایر نودها، `T6-8` تلگرام، `T6-9` کلودفلر)
  - `T7`: کاربران (`T7-1` افزودن، `T7-2` کارت کاربر، `T7-M` مدال ویرایش شامل بخش‌های M1 تا M5)
  - `T8`: گزارش فعالیت
  - `T9`: آمار
  - `T10`: راهنما و سوالات
