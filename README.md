# پنل مِهر (Mehr Panel) - نسخه ۱.۳.۱

سیستم توزیع‌شده مدیریت پروکسی و هسته ترافیکی مبتنی بر Cloudflare Workers و دیتابیس D1 با پشتیبانی از پروتکل‌های VLESS و Trojan.

## ویژگی‌ها
- پشتیبانی کامل از پروتکل‌های VLESS و Trojan (حالت مستقیم و زنجیره‌ای)
- کلاستر نودهای لبه (Edge Nodes) با همگام‌سازی بلادرنگ کاربران
- استقلال کامل از سرور و محیط محلی

## روش‌های راه‌اندازی
1. **ویزارد وب:** اجرای فایل `mehr-wizard.js` در یک ورکر جدید کلودفلر
2. **استقرار دستی:**
   - استفاده از قالب‌های `wrangler.example.toml` برای مستر
   - استفاده از قالب‌های `wrangler.node.example.toml` برای نودهای لبه

## مستندات فنی
- `docs/TROJAN_IMPLEMENTATION.md`: جزییات فنی پیاده‌سازی پروتکل تروجان
- `ARCHITECTURE_RULES.md`: قواعد معماری کلاستر
- `version.json`: وضعیت نسخه پروژه
