# DECISIONS — پروژه مهر (Mehr)

> این فایل تصمیم‌های مهم و تثبیت‌شده پروژه را ثبت می‌کند.
> تصمیم‌های ثبت‌شده نباید بدون دلیل فنی معتبر و بررسی پروژه تغییر کنند.

---

## تصمیم‌های معماری

### 2026-09-23 — معماری اصلی Mehr

**تصمیم:**

Mehr از رابط کاربری Nahan و هسته BPB استفاده می‌کند.

ساختار کلی:

User
↓
Mehr Panel
↓
Modified Nahan UI
↓
BPB Core / Worker
↓
Cloudflare

**نکته مهم:**

Mehr خودش VPN یا Core مستقل ندارد.

---

### 2026-09-23 — حذف UI مربوط به BPB

**تصمیم:**

از BPB بخش UI به عنوان رابط اصلی استفاده نمی‌شود.

BPB در Mehr عمدتاً نقش Core / Worker را دارد.

---

### 2026-09-23 — حفظ قابلیت‌های Nahan

**تصمیم:**

Mehr باید تا حد امکان قابلیت‌های مفید و اصلی Nahan را حفظ کند.

تغییرات UI و قابلیت‌های جدید نباید بدون دلیل باعث حذف قابلیت‌های موجود Nahan شوند.

---

### 2026-09-23 — اضافه شدن Smart Router

**تصمیم:**

بخش «Smart Router / روتر هوشمند» به پنل Mehr اضافه خواهد شد.

این بخش باید به عنوان یکی از قابلیت‌های اصلی پنل در نظر گرفته شود.

**تصمیم:**

## قوانین تغییر تصمیم‌ها

اگر تصمیمی نیاز به تغییر داشت:

1. ابتدا دلیل فنی تغییر مشخص شود.
2. وضعیت فعلی پروژه بررسی شود.
3. تأثیر تغییر بررسی شود.
4. تصمیم جدید در همین فایل ثبت شود.
5. در صورت نیاز `PROJECT.md` و `TODO.md` نیز به‌روزرسانی شوند.
6. تصمیم قبلی حذف نشود؛ وضعیت آن به «Superseded» تغییر کند و تصمیم جدید جایگزین آن شود.
